# Plugins

## PH-13 — Have and manage plugins

> **As a** phone user
> **I want** to see, install, configure and remove plugins
> **So that** I control what each site does in the car.

**Today.** The plugins screen lists what is active and what is not, marks each one as built-in
or installed, and can be filtered. A plugin is installed from a file, and before it is accepted
the app shows what is inside it — every file, with its checksum. Each plugin opens on a detail
screen with what it does, on which addresses, in which environment, and the features that can
be turned on and off one by one. An installed plugin can be removed, and the whole set can be
put back to the defaults, each behind a confirmation. The same screen chooses which plugin
answers voice search, and its menu has "Plugin feedback", on by default, which decides for
every plugin at once whether the car screen says what a plugin just did (CR-24).
